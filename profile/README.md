### ⚡ Highlights

- **Zero Credentials Required**: 100 requests/minute free public tier.
- **Smart Heuristic Verification**: Scores track counts, official artist/composer credentials, and release years.
- **Developer-Friendly**: Standard REST endpoints with sub-50ms cache hits.
